CLI Scheduler Sender

joshuatly/cli-scheduler

Right-click a link or a page and choose Send … to CLI Scheduler. The URL is queued on one of your schedulers with the preset chosen below.

Scheduler instances

Add every scheduler you run. Chrome will ask once for permission to reach each address. The computer running Chrome must be listed in each scheduler's allowed_ips.

Presets

Rules by domain

youtube.com matches youtube.com and every subdomain (www., m., music.). Add a path to narrow it: youtube.com/playlist. The most specific matching rule wins. Each rule sends to one preset on one instance, so a domain can only have one rule.
